# Interactive Sports Analytics Dashboard

## Overview
This project focuses on analyzing sports performance data using Power BI dashboards. The dashboard provides insights into player and team performance metrics through interactive visualizations.

## Features
- Interactive sports dashboards
- Performance trend analysis
- Comparative player statistics
- Data visualization using charts and KPIs
- Analytical reporting using DAX

## Tools Used
- Power BI
- DAX
- Power Query

## Key Learnings
- Data cleaning and transformation
- Dashboard design principles
- Sports data visualization
- Analytical reporting techniques

## Files Included
- Dashboard screenshots
- Project presentation
- Supporting datasets
